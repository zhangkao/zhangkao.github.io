# Kao Zhang · 张考 — Academic homepage

静态 GitHub Pages 个人主页，无需安装依赖或构建。

## 文件

- `index.html`：个人简介、研究方向、论文、经历、项目、专利、课程及联系方式。
- `assets/style.css`：配色、桌面与手机布局、打印样式。
- `assets/main.js`：论文搜索、年份筛选、展开收起及导航高亮。
- `assets/favicon.svg`：浏览器图标。
- `zhangkao_files/`：保留的原有照片、PDF 和历史资源。
- `_backups/homepage-before-20261015-221322.zip`：改版前的完整页面和资源备份，已通过 `.gitignore` 排除，不会随正常提交发布。

## 预览与发布

直接用浏览器打开 `index.html` 即可查看。页面不依赖网络字体、第三方脚本或前端框架，离线也可阅读全部内容；关闭 JavaScript 时会显示全部论文。

将 `index.html`、`assets/` 和需要的 `zhangkao_files/` 一并提交、推送至原有 GitHub Pages 发布分支。仓库原有 Pages 配置继续生效。本次改版没有执行提交或推送。

## 更新论文

页面现为全英文，简介采用第三人称。页面不再展示 AI 翻译标注。生成说明 “This homepage was generated with ChatGPT.” 放在个人简介右上方，手机端自动适配。人物姓名采用拉丁字母拼写，专利标题为说明性译文，专利申请号和原状态保持不变。共同第一作者仅使用 `(co-first author)` 文字说明，不加星号；`*` 仅表示通讯作者。图标使用本地内嵌 SVG，无需图标库或外部服务。联系方式仅保留 `kaozhang@nuist.edu.cn`。

每篇论文对应一个 `<article class="publication" data-year="2026" data-kind="Journal">`。复制现有条目、修改年份、标题、作者、期刊/会议与代码链接，并按年份由新到旧排列。搜索与计数自动读取 HTML 条目；默认显示 6 篇，数量在 `assets/main.js` 的 `limit` 中调整。

当前年份筛选按钮为 2026、2025 和 2024 及以前。新增年度时，同步修改 `index.html` 中的筛选按钮，以及 `assets/main.js` 中 `earlier` 的年份范围。同步更新页脚的最后修改时间。

项目、专利、获奖等内容使用原生 `<details>` 折叠区，可直接编辑对应列表；列表旁的条目数量也需同步更新。科研经费及学生项目按原记录年份倒序分组，专利按申请号中的申请年份倒序分组；这些分组不表示授权年份。每组使用 `.year-group`，添加条目时放入对应年份的列表即可。正文及辅助文字字号在本轮调整中增加约 2px，手机端研究方向和课程列表采用单列排列。

项目记录不展示经费金额，保留项目名称、角色、日期和已有状态。专利作者中的 Kao Zhang 使用 `<strong>` 加粗。著作使用 `.book-entry`，与论文共享年份、标题、作者及出版信息布局，但不参与论文筛选和数量统计；Books 的 `<details>` 设置 `open` 属性，默认展开。2024 年著作保留中国图象图形学学会的机构作者署名，并单独说明 Kao Zhang 的编写与整理工作。毕业去向按学校主页完整列出 18 位学生（研究生 8 位、本科生 10 位），一人一行，保留留学生及协助指导说明；姓名采用拉丁字母拼写。地址仅保留一个完整段落。简介采用文字通栏排版，不展示旅行照片，左侧个人头像保留。简介下方的 Research group 列出胡志华、李明两位老师的主页，链接与中文主页一致。
